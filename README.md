# 多组织指标查询平台

零依赖（Node ≥ 22 内置 `node:sqlite` / `node:http` / `node:test`）的全栈应用，演示多组织层级下的指标查询授权、敏感级别明细限制，以及权限变更对缓存、导出、排队任务和历史快照的传播。

## 运行

```bash
npm start          # http://localhost:3000 （内存库，DB_PATH=./data.db 可持久化）
npm test           # 18 个测试：授权引擎 / 并发授权 / 变更传播
```

## 授权模型

对「用户 U 访问组织 O」按优先级求值，每次求值产出**命中规则**（页面可查）：

| 优先级 | 规则 | 说明 |
|---|---|---|
| 1 | 撤销授权 revoke | 否决一切，最高优先 |
| 2 | 继承 inherit | 用户所属组织的整棵子树 |
| 3 | 例外授权 exception | 显式授予的子树（长期） |
| 4 | 临时授权 temporary | 带 `expires_at` 的显式授予，扫描器每秒处理到期 |
| 5 | — | 无任何覆盖 → 拒绝 |

**敏感级别**：指标有 L1–L4 敏感级，用户有密级。`用户密级 ≥ 指标敏感级` 才返回明细行，否则仅返回汇总值（命中规则中标注"明细受限"）。

**越权防护**：非管理员只能就自己有权访问的组织授权；仅管理员或创建者可撤销授权；导出物仅本人或管理员可下载。

## 权限变更传播（同一事务内完成）

任何授权创建/撤销/到期都会：

1. `perm_epoch + 1` —— 缓存键含纪元，旧纪元键即刻不可达，并物理清除该用户缓存；
2. 重校验**排队中**的任务，失去权限的一律取消（执行中的任务在落库前还会再校验一次）；
3. 按**快照规则**重评估历史快照：快照范围仍被当前权限覆盖 → **保留**；否则 → **失效**（内容不可再获取，下载返回 410，审计留痕）。

## 页面

- **授权树**：组织树上标注每个节点的命中规则（继承/例外/临时/已撤销/无权限），含授权管理与撤销；
- **指标查询**：结果 + 命中规则面板 + 缓存命中标识；
- **导出与任务**：入队导出，任务状态（排队/执行/完成/取消）每 2 秒刷新；
- **快照与缓存**：快照有效/失效及原因、当前缓存键与纪元；
- **审计日志**：授权、查询、缓存失效、任务取消、快照失效全留痕。

## API 摘要

```
GET  /api/bootstrap                 用户/组织/指标/期间
GET  /api/authz-tree?user_id=       授权树（含命中规则）
GET|POST /api/grants                授权列表 / 创建（x-actor-id 头标识操作者）
POST /api/grants/:id/revoke         撤销授权
POST /api/query                     指标查询（授权+敏感级+缓存+快照）
POST /api/exports                   导出任务入队
GET  /api/tasks                     任务列表
GET  /api/tasks/:id/download        下载导出（快照失效 → 410）
GET  /api/snapshots | /api/cache | /api/audit
```
